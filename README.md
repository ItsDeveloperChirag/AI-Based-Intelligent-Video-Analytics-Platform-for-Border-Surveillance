# AI-Based-Intelligent-Video-Analytics-Platform-for-Border-Surveillance
Description: The system receives live CCTV streams through RTSP and processes them using OpenCV, FFmpeg, YOLO11 and object tracking. Detected persons and vehicles are assigned tracking IDs allowing the platform to analyse their movement, trajectory, direction, and dwell time in zone.
